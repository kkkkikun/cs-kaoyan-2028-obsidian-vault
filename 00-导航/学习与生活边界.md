# 学习与生活边界

## 为什么需要边界

散步、健身、游戏、社交、手续、项目都可以有价值。问题是它们的即时反馈强，容易切碎基础学习的长时段；尤其 AI 项目很容易无限延长。

## 三个时间盒

1. **受保护的深度学习**：每天第一个可控的完整时段优先给数学（或当期最重要科目）。期间不查消息、不追 Agent 报告。
2. **机动事务窗口**：签字、报销、琐碎消息集中处理；真正有截止期限的事务例外。
3. **生活与兴趣窗口**：健身、散步和游戏是合理的休息；AI 项目需要设置结束时刻。

## 实际操作规则

- 朋友临时邀请：先说自己何时能结束学习，再商量时间；不需要一律拒绝。
- Agent 有新进度：先放入 [[AI项目停车场]]，固定每周 1–2 次集中审阅。
- 想学新课程：先写入 [[课程候选池]]，现阶段**不同时激活超过一个额外课程**。
- 被打断后恢复：写一句「下一步动作是什么」，回到小任务，不用重新做复杂计划。
- 实际学习质量 > 打卡时长；允许有运动、休息和无负罪感的娱乐。

## 两周实验

- [ ] 每周保住 5–6 个完整数学学习块。
- [ ] 每天英语不断线（特殊繁忙日缩到 20 分钟）。
- [ ] 记录非紧急打断来源；下周只调整一个最影响专注的问题。
- [ ] 每周至少半天相对自由的恢复时间（可随课表调整）。
