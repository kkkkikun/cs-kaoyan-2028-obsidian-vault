# 毕设一页纸｜显影 = LocalPixt

**它是一个毕业设计，不是两个项目，也不是兴趣项目停车场里的任务。**

- **做什么**：完全离线的 Android 中文相册语义搜索（Chinese-CLIP + 向量索引）。
- **已经有的成果**：W1 原生工程与模型管理、W2 受控夹具、W3 真实相册索引和搜索 UI 均有通过记录。2026-10-18 日志记录 2726 张真实相册索引完成、失败数 0；2026-10-19 W3 查询及详情交互记录 PASS。
- **尚未完成**：全部功能与权限边界验收、正式实验与论文材料、可交付 APK、学校正式毕业流程。
- **时间目标**：2027-02 前争取完成主要技术交付，之后把精力留给考研、找工作；**不是学校正式认定毕业完成**。
