## Obsidian 与 GitHub

新电脑第一次使用：

```powershell
git clone https://github.com/kkkkikun/cs-kaoyan-2028-obsidian-vault.git
```

使用 Obsidian 将克隆得到的根文件夹打开为 Vault，建议把 `本周计划` 和 `每日小记` 加书签，折叠 `90-资料库`。

如果已有本地克隆，先确认没有未提交或未保存的修改，再执行 `git pull --rebase`。GitHub 仓库是公开的，提交前需先检查 `git status` 和文件差异，仅发布你愿意公开的笔记。

**特别提醒：`00-日常/每日小记.md` 是公开仓库中的文件。** 推送个人感想时任何人都可能看到。敏感心事、身份信息、准考证、照片、账号凭据和未公开毕业设计资料应另放在私有 Vault，不要上传。

**优先级：数学一持续积累 → 2026-12-12 四级 → 显影 / LocalPixt 毕设提前交付；408 从 2027 年系统推进，OS/算法作为有边界的深化。**
