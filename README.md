# CS × 2028 考研 · Obsidian Study Vault

一套 **可直接用 Obsidian 打开** 的公开 Markdown 学习仓库，面向 **2027 年底初试／2028 年入学** 的数学一、英语、408、政治准备，同时保留 OS / Rust、C++ 算法与 CS 基础的实践记录，并把 **显影（LocalPixt）本科毕业设计**作为单独的提前交付项目管理。

> 本仓库是一套计划和知识管理**模板**，不是已经完成的学习记录；所有任务默认未勾选。适合以实际课表和考试公告定期调整。2027 年底正式初试日期、招生科目和年度大纲，以官方发布为准。

## 从哪里开始

1. 在 Obsidian 打开本仓库所在**文件夹**为 Vault（不是直接打开 ZIP 文件）。
2. 从 [[00-主页]] 进入：学习总路线、数学月计划、四级冲刺、408 与每周复盘。
3. 从 [[本周计划]] 选择 **1 个必须完成的数学学习块**，再安排英语和技术学习。
4. 使用 `05-模板` 中的模板记录：日记、周复盘、错题、真题、算法题与 OS 实验。
5. 每周更新进度，不自动认定「打开课程视频=已掌握」。

## 结构

- `00-导航`：使用方法、路线图、时间预算与不被打断的原则。
- `01-考研`：数学一（基础 30 讲／强化 36 讲／1000 题 A/B／真题模拟）、四级与考研英语、408、政治。
- `02-CS内功`：OS/Rust、C++ 与算法、CS 自学资源、开源实践，以及 `毕业设计/` 下的显影（LocalPixt）交付路线。
- `03-计划与复盘`：**2026-10 到 2027-12** 的逐月计划、每周复盘和计划。
- `04-日记`：日常学习记录（本仓库不预填私人记录）。
- `05-模板`：Obsidian 内置模板插件即可使用，无需第三方插件。
- `06-附件`：本地附件目录；公开推送前检查隐私和版权。

## 本地使用与 GitHub 同步

首先参考 [[GitHub发布指南]] 将本 Vault 首次发布。

```bash
git clone https://github.com/kkkkikun/cs-kaoyan-2028-obsidian-vault.git
```

然后在 Obsidian 选择 **Open folder as vault / 将文件夹作为仓库打开**，选择克隆后的仓库根目录。

建议先 `git status` 检查公开范围，**只 `git add` 确认可公开的笔记文件**，再 `git commit` 与 `git push` 备份；如使用社区插件 **Obsidian Git**，请自行安装并检查插件权限，避免在多个设备同时编辑时发生冲突。

> **公开仓库注意**：切勿提交真实姓名、学号、电话、家庭或学校具体行程、成绩单、密钥、个人聊天、报销材料，或未获得授权的教材/真题原文。`.gitignore` 会忽略部分 Obsidian 工作区文件，但不能自动识别所有隐私数据。

## 使用约定

- 数学讲次按当前规划的教材结构组织：基础高数 18、线代 6、概率 6；强化高数 18、线代 9、概率 9。**具体讲名与题目编号以手中教材实际版次为准**。
- A 组同步基础，B 组同步强化；题本有出入可修改任务名称，不追求照单全刷而牺牲理解。
- 12 月 12 日四级是 2026 年短期节点；四级后英语转长期考研路线。
- 目标是持续积累基础而非把日程排满；忙碌周使用 [[低负荷保底计划]]。
