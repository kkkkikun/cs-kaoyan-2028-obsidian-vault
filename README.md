> **每天只打开 [[本周计划]]。** 这个 Vault 不是 80 多项待办；其他都是需要时才查的资料。

## 只需要认识两个文件夹

| 目录 | 用途 |
| --- | --- |
| `00-日常/` | **主页、本周计划、毕设一页纸**：日常只看这三页 |
| `90-资料库/` | 原有数学逐讲、四级、408、OS/Rust、C++、开源 PR、详细毕设、15 个月计划、错题模板等：**不用全部阅读** |

数学一是长期主线；2026-12-12 的四级是近期考试；显影（LocalPixt）是一个需要提前推进的毕业设计。OS、开源和其他 AI 项目不抢日常学习块。

## 在 Obsidian 打开

```powershell
git clone https://github.com/kkkkikun/cs-kaoyan-2028-obsidian-vault.git
```

在 Obsidian 选择「打开本地文件夹作为仓库」，选择克隆后的**整个文件夹**。打开 `00-日常/00-主页.md`，建议将 `本周计划` 加入书签，并在文件列表中折叠 `90-资料库`。

已有本地克隆时，先检查本地是否有未提交变更，再 `git pull --rebase` 更新。这次把原有文档移入资料库，Git 可能显示大量移动记录，但内容并非删除。若你的本地库存在修改，先保存或提交后再拉取，不要强行覆盖。

## 需要资料时

从主页里的三个链接进入数学、英语、毕设细节。高级资料在 `90-资料库` 按原有目录保留；Obsidian 的 `[[Wiki 链接]]` 可以跨文件夹跳转。日记和模板插件的路径已同步至新目录。

## 公开仓库注意

本仓库是 **Public**。不要提交私人日记、学校证明、证件、成绩截图、账号或 API 密钥、原始相册图片和任何未公开的毕设材料。提交前查看 `git status` 与差异，尽量只 `git add` 明确允许公开的文件。可将私人笔记单独放在私有 Vault。
