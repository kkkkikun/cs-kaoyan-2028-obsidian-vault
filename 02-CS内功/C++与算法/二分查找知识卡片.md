# 二分查找：知识卡片

## 思想

在一个有单调性或已排序的搜索空间中，通过比较缩小候选范围。关键是**边界定义与循环不变量**，不是死记哪一次要加一。

## C++17 示例：查找首个 ≥ target 的位置

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
int main() {
    std::vector<int> a{1, 2, 2, 5, 8};
    int target = 2;
    auto it = std::lower_bound(a.begin(), a.end(), target);
    std::cout << (it - a.begin()) << "\n";
}
```

练习：用半开区间 `[l, r)` 自己实现 `lower_bound`，给出循环不变量、终止条件和正确性论证。

## 自查边界

- [ ] 空数组、单元素数组。
- [ ] target 小于所有值 / 大于所有值。
- [ ] 多个重复元素。
- [ ] mid 的计算和区间是否收缩。
