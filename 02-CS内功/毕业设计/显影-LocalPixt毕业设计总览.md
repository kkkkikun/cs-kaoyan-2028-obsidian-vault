# 显影 / LocalPixt｜毕业设计总览

> **同一项目的两个名称：LocalPixt = 显影。**
> 定位为 **提前完成的本科毕业设计**，不是两个独立 AI 兴趣项目，也不是普通的待办停车项目。
> 目的：尽早形成可展示、可验证、可用于论文的成果，让大四有更多时间复习 2028 考研、参加招聘和完成学校的正式毕业流程。

## 选题与范围

- 当前项目文档采用的题目：《基于 CLIP 与 HNSW 的手机相册语义搜索系统设计与实现》。
- 核心产品：**端侧离线 Android 手机相册语义检索**，自然语言检索照片，尽量保护相册隐私。
- 主技术：Chinese-CLIP、ONNX Runtime Android、向量检索 / HNSW、SQLite 元数据、Kotlin + Jetpack Compose。
- 交付链路：**可复现技术验证 → 可运行 APK → 权限与相册索引 → 查询交互 → 量化实验与论文证据 → 技术冻结与答辩资料**。
- 对话式整理、额外模型和桌面伴侣端等作为扩展候选；不能拖累核心验收。

## 目前的定位

**ACTIVE — 战略必做 / 学业交付，不进入 [[AI项目停车场]]。**

它不是想做就做的玩具，也不能因此无限占据每天的学习时间。每周只锁定一项明确可验收的毕设进展，保留数学一与英语的受保护学习块。

- 近期优先：[[显影-交付里程碑与验收]] 中的核心稳定性 / 最小产品验收。
- 考虑 2026-12-12 四级：四级前降低功能扩展，**不因为项目兴奋而牺牲考试**。
- 目标：2027 年 2 月前争取完成**技术层面提前交付包**（产品、实验、论文素材），给大四腾出余裕。
- **正式毕业设计**仍以学校开题、中期检查、论文规范、导师要求、答辩和官方时间安排为准；提前做完代码 ≠ 正式毕业验收通过。

## 个人成长价值

1. **毕业设计**：减少大四学业任务挤占考研和求职的风险。
2. **简历项目**：形成完整需求、系统设计、评测和演示，而不只是一个 AI Demo。
3. **CS 内功**：向量检索、近似最近邻、索引维护、端侧性能与可靠性，关联 [[408-数据结构]]、[[408-计算机组成原理]]、[[408-操作系统]]。
4. **工程实践**：真实设备测试、实验可复现性、离线隐私边界、论文可审计性。
