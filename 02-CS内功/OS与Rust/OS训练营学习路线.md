# OS / Rust 训练营学习路线

参考：[OS2Edu 2026 秋冬季课程](https://opencamp.cn/os2edu/camp/2026fall/stage/1)。当前考研主线的数学和英语更紧迫，OS 训练营采用**自定进度、理解优先**模式。

## 阶段划分

- [ ] Rust 基础：所有权、借用、生命周期、泛型、Trait、错误处理。
- [ ] Rustlings 按基础难点分类复盘，而不仅统计题数。
- [ ] RISC-V / 汇编 / 特权级 / 中断概念。
- [ ] rCore / 操作系统实验：系统调用、进程调度、页表、文件系统等（以实际训练营任务为准）。
- [ ] 能用自己的话解释并验证已完成实验。

## 一周只做一个最重要实验任务

> 本周目标：____ ；预计连续学习时间：____ ；独立证明掌握的方式：____

学习记录请使用 [[OS实验记录模板]]。课程目录、截止时间可能更新，必须看官方公告；本仓库不会自动同步训练营进度。

## 与考研的关系

- 训练营帮助理解 [[408-操作系统]]、[[408-计算机组成原理]] 的机制。
- **理解内核不等于会做 408 题**，务必将概念映射到典型题练习。
- 2027 年中以后若学科压力较高，可以暂停训练营任务，不因此否定之前成果。
