# CS 内功地图

**原则：408 是 CS 基础的主要骨架；OS / C++ 实践帮助深化理解，不再叠加多门完整课程。**

## 三条能力链

1. **算法**：C → [[C++算法训练路线]] → [[算法题单]] → [[408-数据结构]]。
2. **系统**：C / Rust → [[OS训练营学习路线]] → [[408-计算机组成原理]] 与 [[408-操作系统]]。
3. **长期补齐**：按薄弱点从 [[课程候选池]] 中挑选 CSDIY / CSAPP / CS61C 等内容。

## 通过实际能力验收

- 是否能独立写出关键 C++ 算法并解释复杂度？
- 是否能解释内核机制、虚拟内存或并发控制，而不仅是让 AI 完成实验？
- 是否能用文字或图复述重要原理？
- 是否能将抽象概念用于 408 题型？
