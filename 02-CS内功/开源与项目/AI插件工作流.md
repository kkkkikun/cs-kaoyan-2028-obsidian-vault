# AI 插件工作流

> 你已在 Obsidian 安装 AI 插件，但目前**没有确认插件名称、模型、数据发送方式或权限**。以下是所有支持选中文本提问的 AI 插件都适用的安全工作流，不涉及特定插件菜单。

## 先处理安全设置（公开 GitHub 仓库）

1. 了解插件是否将选中的笔记、整个 Vault 或附件上传给云模型；检查隐私政策、索引范围和日志保存方式。
2. 只让插件访问可以公开的学习笔记。**不要**输入 API Key、GitHub Token、姓名/学号、详细行程、成绩单、学校手续、私人对话或本地机密代码。
3. 建议把个人信息放在单独的**私有 Vault**；如果仅为临时私密草稿，可以使用此仓库本地 `99-私人笔记/` 文件夹（被 .gitignore 忽略），但被忽略不代表 AI 插件不能读取，仍要控制插件索引范围。
4. 禁用或忽略上传 `.obsidian/plugins/` 的插件配置与模型密钥；不要把整个插件工作目录提交到 GitHub。
5. 如果插件可以自动写入或调用工具，先使用**仅提出建议／显示 Diff、由你确认**的模式，避免一次性覆盖学习记录。

## 每天：把 AI 当学习教练，而不是替答者

在 [[本周计划]] 或 [[数学一总览]] 的当前段落选中文本，提问：

```text
根据我选中的学习计划，只为今天安排一个 90 分钟数学学习块和一个 30-60 分钟英语学习块。
不要新增项目，不要假设我已完成未勾选的任务。
每项要给出可验证的产出和中途被打断后的恢复点。
```

做数学错题时：

```text
只提示当前解法的第一个错误、需要复习的定义或下一步提示，不要直接给最终答案。
等我再次尝试后，再评估证明是否严谨。
```

## 每周：让 AI 帮你清理，而不是扩展待办

选中 [[开源贡献记录]] 和 [[AI项目停车场]] 的相关内容，再提问：

```text
请把记录按 DONE / REVIEW_WAIT / CANDIDATE / PARKED / BLOCKED 分类。
只依据原文中的 URL、日期、PR 状态与测试证据。
缺少公开证据必须写“待核实”；不要宣称已合并、已验收、已认领。
最后仅建议一个不超过 90 分钟的可选技术任务，并说明为什么可推迟。
保持数学一和英语的优先级，不新建项目。
```

复盘时：

```text
总结我本周真正完成的学习成果：独立解题、已验证的实验、真实通过的测试。
请分开“做了什么”和“理解了什么”，列出最重要的 2 个薄弱知识点。
把下周计划限制在现实可执行的时间预算内。
```

## 毕业设计协助：不要和项目停车场混淆

选中 [[显影-交付里程碑与验收]] 里的一个任务后提问：

```text
这是 LocalPixt（也叫显影），一个需要提前完成的毕业设计，不是普通兴趣项目。
请根据选中文本帮我写一个可以被测试验证的 2 小时开发 / 文档任务。
仅引用已明确的本地证据；缺少报告时写“待核实”。
不添加额外功能或扩充范围，并列出明确验收条件。
不要把本地源码、私人照片、未公开实验数据或学校文档复制到公开 Obsidian。
```

## 最少需要打开的页面

1. 日常：[[00-主页]] → [[本周计划]] → 当天学科。
2. 周末：[[每周复盘指南]] → [[开源贡献记录]] → [[AI项目停车场]]。
3. 只有真正有上游更新或可验证任务，才打开 GitHub / AI Agent 去开发。

> Obsidian 的 AI 插件与 ChatGPT 的 GitHub 连接**不是自动互通**；插件不会自动知道线上 PR 的最新状态，必须明确联网查询或提供新的事实后再更新。
