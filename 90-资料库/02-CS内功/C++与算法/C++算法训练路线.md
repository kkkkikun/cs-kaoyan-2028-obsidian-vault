# C++ 算法训练路线

已有 C 与 Python 算法基础，可采取 **C++17 常用语法 + STL → 边做题边学**，不必先完成一整套现代 C++ 工程课程。

## 第一步：C++ 竞赛常用工具

- [ ] 输入输出、函数、引用与常见类型坑。
- [ ] `vector`、`string`、`pair`、`sort`、`lower_bound`。
- [ ] `map`、`set`、`unordered_map`、`queue`、`stack`、`priority_queue`。
- [ ] 迭代器、lambda、递归和基本泛型函数的使用。

## 第二步：算法专题（与 408 联动）

- [ ] 排序、二分、双指针、前缀和。
- [ ] 栈、队列、哈希、树和二叉树。
- [ ] 图遍历、最短路径、并查集。
- [ ] 贪心、基础动态规划、搜索与回溯。

## 做题纪律

1. 先读题并独立推导方法，再寻求 AI 的**提示而非完整答案**。
2. 写清时间/空间复杂度，区分边界情况。
3. AC 后写一段「为什么正确」；遇到难题回到知识点。
4. 2026 四级备考及 2027 数学高强度阶段，竞赛专项让位于考研主线。
