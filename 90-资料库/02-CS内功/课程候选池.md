# CSDIY / CS 课程候选池

> 课程选择原则：**一次只激活一个与当前瓶颈直接相关的扩展课程**。它不是任务总清单。

| 方向 | 候选资源 | 何时启用 |
| --- | --- | --- |
| CS 自学地图 | [CSDIY](https://csdiy.wiki/) | 查知识空白及精选课程 |
| 计算机系统 | CSAPP | 需要补 C、汇编与存储器层次时 |
| 体系结构 | CS61C / 相关公开课 | 学 408 计组时选择针对性实验 |
| 操作系统 | MIT 6.S081 / rCore | OS 实验出现实际理解瓶颈时 |
| 算法 | OI Wiki / USACO Guide | 算法题出现对应薄弱点时 |

## 一门新课开始前的问题

1. 它能解决我本月哪一个真实难题？
2. 是否可以只学习其中 1–2 节，而不是全程开新坑？
3. 哪一个现有任务会为它让位？
