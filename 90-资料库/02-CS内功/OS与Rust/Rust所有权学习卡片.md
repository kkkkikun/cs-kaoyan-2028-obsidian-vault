# Rust 所有权：学习卡片

## 核心问题

- 谁拥有一个值？何时发生移动（move）或复制（copy）？
- 为什么同一作用域中的共享引用与可变引用有互斥约束？
- 借用与生命周期标注解决的是哪些安全问题？

## 自己写最小例子

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // 所有权移动
    println!("{}", s2);
}
```

修改它以展示 `&String`、`&mut String` 的区别；尝试制造编译错误，理解错误提示，而不只是要求 AI 修好。

## 独立验收

- [ ] 能解释为什么 `String` 与某些 `Copy` 类型赋值语义不同。
- [ ] 能编写示例说明不可变和可变借用的约束。
- [ ] 能说清楚生命周期说明符不是「人为延长变量生命」。
