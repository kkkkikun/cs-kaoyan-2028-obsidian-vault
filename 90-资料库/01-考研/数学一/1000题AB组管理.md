# 1000 题 A／B 组管理

A 组跟随 [[数学一基础30讲进度]]；B 组跟随 [[数学一强化36讲进度]]。**请根据手中题本的实际版次填题号**；不猜测或伪造题号。

## 每讲记录卡（复制使用）

```md
### 高/线/概 第 __ 讲
- 教材版次／题本版次：
- A 组对应页/题号：
- [ ] 独立完成并订正 A 组
- B 组对应页/题号：
- [ ] 独立完成并订正 B 组
- 卡点（概念/方法/计算/审题）：
- 需二刷题号：
- 下次回访日期：
```

## 不要掉进的陷阱

- 只刷 A 组不回顾基础：会造成公式记忆薄弱。
- 只听强化不做 B 组：遇到综合题仍不会动笔。
- 把一道题做出答案就算学会：应能再次独立完成，并解释关键步骤。
- 为了刷题总数无限加时：结果挤占英语、408 和睡眠。

## A 组与 B 组切换

- **A 组**：理解题目对应的基础定义、公式与常用方法，先独立做。
- **B 组**：归纳跨知识点方法，允许难题多次尝试，着重建立解题策略。
