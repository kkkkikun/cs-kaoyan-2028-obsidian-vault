# 数学一核心知识清单（按知识主题）

> 用于考前对照检查，非完整考试大纲；必须与当年官方大纲核对。

## 高等数学

- [ ] 函数、极限、连续与数列极限。
- [ ] 一元微分学：定义、计算、几何意义、中值定理、证明。
- [ ] 一元积分学：不定/定积分、技巧、几何与物理应用。
- [ ] 多元微分学与极值、条件极值。
- [ ] 二重/三重积分、曲线与曲面积分、空间问题（数一重点）。
- [ ] 微分方程及基本求解方法。
- [ ] 无穷级数的判别、幂级数、展开与相关应用。

## 线性代数

- [ ] 行列式与矩阵运算、秩、逆矩阵。
- [ ] 向量组线性相关性、线性方程组。
- [ ] 特征值特征向量、相似对角化、实对称矩阵、二次型。

## 概率论与数理统计

- [ ] 随机事件与条件概率、独立性。
- [ ] 随机变量及分布，二维随机变量与函数分布。
- [ ] 数学期望、方差、协方差等数字特征。
- [ ] 大数定律与中心极限定理。
- [ ] 统计量、抽样分布、参数估计、假设检验等适用考点。
