# 英语阅读与长难句

## 一篇阅读如何复盘

1. 限时读一遍，记录卡住的句子。
2. 找主干：主语、谓语、宾语；辨认从句、非谓语与插入成分。
3. 把抽象句子用自己的中文解释清楚，而不是逐词硬翻。
4. 对每个阅读题写出正确选项的证据和错误选项的干扰方式。
5. 隔 3–7 天复读，检验是否真的理解。

## 常见难句诊断

- [ ] 主谓宾核心结构无法快速判断。
- [ ] `which/that/what` 从句边界模糊。
- [ ] 非谓语、同位语或长插入成分影响理解。
- [ ] 不认识核心词，或只记得孤立中文释义。
