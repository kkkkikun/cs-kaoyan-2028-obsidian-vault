# 数学一总览

**优先级 P0**。采用「理论→自己做题→错题诊断→间隔复做」的完整闭环。

## 四阶段

1. [[数学一基础30讲进度]]：2026-10 至 2027-03，基础 **高18 + 线6 + 概6**，配套 1000 题 A 组。
2. [[数学一强化36讲进度]]：2027-04 至 2027-08，强化 **高18 + 线9 + 概9**，配套 B 组。
3. [[数学一真题模拟管理]]：2027-08 末开始诊断，9–10 月核心真题。
4. 2027-11 至初试：模拟卷、复盘、旧题重练。

## 章节学习完成标准

- [ ] 理论能脱离视频用自己的话解释。
- [ ] 教材例题先自己尝试再看讲解。
- [ ] 1000 题对应 A/B 组独立尝试、标记错因。
- [ ] 3–7 天后能重新做对具有代表性的错题。
